# Global Music Trends – Reproducible Analysis

This repository contains a fully reproducible data analysis for the project:
**GLOBAL MUSIC TRENDS: A data-driven analysis of cultural differences in music streaming**.

## Dataset
The dataset is publicly available on Kaggle:
https://www.kaggle.com/datasets/anxods/spotify-top-50-playlist-songs-anxods

## Repository Structure
- notebooks/: Jupyter notebook containing the full analysis
- data/raw/: place Kaggle CSV files here (not included in the repo)
- outputs/figures/: generated plots (optional)

## Reproducibility
1. Download the dataset from Kaggle
2. Place the CSV files inside `data/raw/`
3. Install dependencies:
pip install -r requirements.txt
4. Run the notebook in `notebooks/`
